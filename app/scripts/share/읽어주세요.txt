[실행]
- Mac: '실행하기(Mac).command' 더블클릭 (처음엔 우클릭 → 열기)
- Windows: '실행하기(Windows).bat' 더블클릭
→ 브라우저가 자동으로 열려요. PC에서는 휴대폰 틀로, 휴대폰에서 열면 전체 화면으로 보여요.
- 휴대폰으로 보려면: PC와 같은 와이파이에서, 실행 창에 나온 http://(PC IP):8080/index.html 주소를 휴대폰 브라우저에 입력
- Python 이 없으면: Node 가 있는 PC에서 이 폴더에서 'npx serve site' 실행 후 나온 주소로 접속
- 서버 없이 index.html 을 직접 더블클릭하면 동작하지 않아요 (꼭 실행 파일로 여세요)

[처음 해볼 것]
1. 앱 소개 4장 → 홈
2. 쇼츠 탭: 영상 넘기기, 상단 막대 끌기, 하트(찜), 댓글
3. 탐색 → 작품 → 1화 보기 (세로 웹툰) → 하단 '조각 사기'
4. 청약: 금액 → 확인 → 키움증권 화면 → 결제 → '내 펀딩 보기'
5. MY: 출석 체크, 지갑 충전·출금, 투자성향 확인, 유료 회차를 키움 포인트로 열기
6. 다 해봤으면 MY 맨 아래 '처음 상태로 되돌리기' (두 번 누르기)
