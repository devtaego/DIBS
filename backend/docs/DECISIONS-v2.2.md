# v2.2 조정값 결정 (2026-11-21)

기획서 v2.2(3-4장까지)와 화면설계도 'Screens – MVP v2'가 서로 다르거나 비어 있던 값을 아래처럼 정했다.
기준은 세 가지다: 기획서와 화면이 둘 다 맞는 값, 법·시장 수치와 맞는 값, 작가·투자자·Dibs 중 한쪽만 손해 보지 않는 값.
모든 값은 `app/core/config.py` 설정값이고, 펀딩별 값은 심사 때 덮어쓸 수 있다(`REVIEWABLE_TERMS`).

## 1-1. 추가 확정 (같은 날, 팀 위임으로 확정)

| 항목 | 정한 값 | 이유 |
|---|---|---|
| 회차 뷰어 이벤트(데이터팀 코드 1102) | `VIEW_START` | 회차 뷰어 진입 이벤트가 이것 하나뿐 |
| 확정 분기 | 배당을 **지급까지 마친** 분기, 진행 중 분기는 제외 | 화면 '가장 최근 지급 완료 분기'와 같다 |
| 2차·해외 IP 수익 | 매출 종류 `SECONDARY_IP`. 계약서·정산서 증빙 필수, 실비만 빼고 1차와 같은 60/30/10 | 비율을 따로 두면 설명할 숫자가 늘어난다. Dibs 에이전시 몫은 10%뿐 |
| 작가 지급(모금액 80%) | 상장 때 40%, 약정 회차 절반 연재 30%, 완결 30% (신탁 보관 후 분할) | 기획서 1-3 '신탁에서 나누어 지급'을 날짜가 아니라 연재 진행에 묶어 연재 중단 위험을 줄인다 |
| 후원금 회수 | 하지 않음 | 작가 몫 60%가 업계 하한이라 더 떼면 연재 중단 위험이 커진다. 투자자 보호는 유보금 5%·분할 지급·창작자 토큰 보호예수·귀책 반환 청구가 맡는다 |
| 창작자 토큰 매수 | 불가 (보호예수 뒤 매도만) | 기획서 2-3 이해상충 |

## 2. 화면 수정 요청 (디자인)

- 분기 배당: '세전 배당금 = 실입금액'이 아니라 원천징수 15.4% 줄을 넣는다.
- 주문 시트 수수료: '0원' 대신 실제 계산값(0.015%, 원 미만 버림).
- 펀딩 금액 → 조각: '5.5토큰' 대신 '55조각'처럼 정수 (1조각 1,000원).
- 씨앗 구매: 모의 모드에서는 예치금 → 씨앗 전환이 막혀 있다(실거래 모드 전용). 시연은 PG 결제로 보여 준다.
