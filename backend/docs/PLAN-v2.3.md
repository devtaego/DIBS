## **0. 문서 사용법**

### **0-1. 이 문서가 정하는 것**

| 대상 | 이 문서에서 볼 곳 |
| --- | --- |
| 디자이너(피그마) | 4장 IA, 5장 앱 화면정의서(시안 프레임 매핑), 15장 시안 수정 요청 |
| 앱 FE | 3장 정책, 4~5장, 10장 API, 14장 설정값 |
| 웹 FE(스튜디오·어드민) | 6~7장, 10장 API |
| BE | 3장 정책(규칙의 원본), 8~13장 |

v2.3은 0~3장, 14장, 15장, 17장을 고쳤다. 4~13장과 16장은 v2.2 그대로이며, 3장과 다르면 3장을 따른다. API 원문은 저장소 `backend/docs/API_SPEC.md`(147개 엔드포인트), 결정 근거는 `backend/docs/DECISIONS-v2.2.md`다.

### **0-2. 표기 규칙**

- **정책 우선순위:** 3장 정책 > 5~7장 화면 설명 > 시안. 서로 다르면 3장을 따른다.
- **금액:** 모든 금액은 원(KRW) 단위 정수(`BIGINT`)로 저장·계산한다. 소수점 금액은 없다(예외: 보유 증권의 평균 매입가는 소수 4자리까지 저장하고 화면에서는 원 단위로 반올림).
- **씨앗:** 화면 단위는 씨앗, 장부 단위는 원이다. **씨앗 1개 = 100원**(`CFG.coin.seedUnitWon`). API는 원 금액(`coin`)과 씨앗 개수(`seeds`)를 함께 준다. 1화 300원 = 씨앗 3개.
- **조각:** **1조각 = 1,000원**(`CFG.funding.unitPrice`). 펀딩은 1,000원 단위라 소수 조각이 없다(55,000원 → 55조각).
- **시간:** 서버는 UTC로 저장하고, 화면 표시와 정책상 날짜 경계(일·분기)는 KST(UTC+9) 기준이다.
- **설정값:** `CFG.xxx`로 표기한 숫자는 어드민에서 바꿀 수 있는 설정값이다(14장). 괄호 안은 기본값이다. 펀딩별로 다를 수 있는 값은 심사 때 덮어쓴다.
- **⚑ 표시:** 기획자가 명시하지 않아 이 문서에서 정한 구현 항목이다(17-2). **검토안**은 운영 확정 전 개발·데모에 사용하는 값이다(17-3). v2.3에서 확정한 값은 17-1에 근거와 함께 모았다.
- **시안 표기:** `[시안 05-3]`은 피그마 'DIBS 앱 화면 · 흐름별 37종'의 해당 프레임이다. `[시안 없음]`은 기존 시안 컴포넌트(카드, 버튼, 칩, 바텀시트, 탭바, 다크 테마, 주황 포인트 컬러)를 조합해 새로 그린다.

## **1. 서비스 개요**

### **1-0. 웹툰 웹소설 토큰 가치 성장시나리오**

!image.png

### **1-1. 한 줄 정의**

Dibs는 정식 연재 전인 웹툰·웹소설을 독자가 먼저 보고, 마음에 드는 작품의 크라우드 펀딩에 참여해, 성공 시 조각(토큰증권)을 받고, 상장 후에는 그 조각을 사고팔며, 작품 수익의 투자자 몫을 분기마다 배당받는 앱이다.

### **1-2. (경인 수정)지적재산권(IP) 수익원 용어정리**

#### 1. 비슷한 개념과의 구분

- **원고료(MG형태로 많이 사용)** : 회차를 연재한 대가로 받는 고정 금액입니다. 노동에 대한 대가
- **저작권료(인세·RS)**: 작품이 팔린 만큼 따라오는 변동 수익입니다. 권리에서 나오는 수익입니다.
- **판권료**: 2차적 저작물 작성권(드라마화 등)을 허락하는 대가입니다. 저작권료의 일부로 봅니다.
- **RS (Revenue Share, 수익배분)**: 매출의 몇 %를 받을지 비율로 정하는 방식입니다.
- **MG (Minimum Guarantee, 최소보장금)**: 연재 전에 미리 주는 선지급금입니다. 나중에 RS 정산액에서 차감되기 때문에, MG를 다 갚기 전까지는 추가 정산이 없습니다.
- 비율은 **계약마다 크게 다릅니다.** 업계 표준 요율은 따로 없습니다.

| 구분 | 내용 |
| --- | --- |
| **1차 연재 수익** | 플랫폼(Dibs, 선공개 독점 12개월 뒤의 네이버웹툰·카카오페이지·리디·문피아 등)의 유료 열람, 미리보기, 대여·소장 결제, 광고 수익 |
| **2차적 저작물 수익** | 드라마·영화·애니·게임 판권(라이선스)료, 단행본 출판, 굿즈·캐릭터 사업 |
| **해외 수익** | 번역 연재(라인웹툰, 픽코마 등)나 해외 판권 수출 |

#### 1-3. DIBS와 이해관계자 간의 업무범위 정의

- 창작자 : 창작물 제작
- 에이전시 : 기획 & 작업 지원
- 증권사 : 발행, 계좌관리, 청약금 예치
- 장외거래소 : 상장 종목 매매 체결(거래 수수료 수취)
- 신탁 : 최소 유보금·작가 지급 전 금액·배당 재원 보관
- DIBS : 수익배분, 유통(창작물), 작가 홍보, IP 확장(1차, 2차, 해외)

### 1-3. 플로우 설명

!image.png

**[등록 · 계약] 창작자 ↔ Dibs**

1. 창작자가 Dibs에 프로필과 작품 일부(샘플 회차 3개 이상)를 등록한다.
2. Dibs가 정책 기준에 따라 창작자와 작품을 검토한다.
3. 검토를 통과하면 창작자와 조건부 독점계약을 맺는다. 계약 범위는 1차 연재 · 2차 IP · 해외 판권 · 수익권 · 작가 지급금 · 창작자 토큰 배정이다. 창작자는 서명 후 계약을 철회할 수 없고, 계약 효력은 토큰증권 발행 시점부터 생긴다.

**[펀딩] 투자자·독자 ↔ Dibs ↔ 증권사**

1. 계약이 끝나면 크라우드 펀딩을 시작한다. 펀딩 기간 동안 독자는 공개 회차(최대 3화)를 무료로 감상하고 관심 있는 작품을 찜한다. 상장 전에는 유료 미리보기가 없다. 투자자는 증권사 계좌를 연계해 청약하고, 청약금은 증권사에 예치된다.
2. 펀딩 결과
    - 5-1. 목표에 도달하면 증권사가 토큰증권을 발행한다. 이때 계약 효력이 생긴다.
        - 투자자 청약분이 초과되면 균등 20% · 비례 80%로 배정한다. 균등분이 참여자 수보다 적으면 공개 추첨으로 1조각씩 준다.
        - 전체 발행량의 **5%**를 창작자에게 토큰(지분)으로 배정한다(투자자 배정 수량 × 5/95, 내림).
        - 창작자 토큰은 상장 후 **12개월** 동안 팔 수 없다(보호예수). 그 뒤에는 팔 수만 있고, 창작자는 자기 작품 조각을 살 수 없다.
    - 5-2. 목표에 미달하면 증권사에 예치된 투자금을 전액 환불하고 계약은 소멸한다. 창작자는 **30일** 뒤 작품을 다시 등록할 수 있으며, 이때 검토와 계약을 처음부터 다시 한다.

**[집행] Dibs ↔ 증권사 · 신탁 · 에이전시 · 창작자**

1. 확정 모금액은 네 곳에 쓴다. 최소 유보금과 지급 전 작가 몫은 신탁에 보관한다.

| 쓰임 | 비율 | 받는 곳 |
| --- | --- | --- |
| 작가 몫(작가 지원 + 작가 지급금) | **80%** | 신탁 보관 후 분할 지급(아래 3) |
| 토큰 발행 실비 | **12%** | 증권사(증권신고·법률·회계·발행) |
| 최소 유보금 | **5%** | 신탁. 완결이면 작가, 중단이면 보유자(3-9) |
| Dibs 펀딩 운영비 | **3%** | Dibs |

2. 작가 지원 중 홍보는 Dibs가 맡는다. 기획 · 작업 지원은 Dibs가 직접 하거나, 일이 많으면 외주 에이전시와 협업한다. 외주 비용은 작가 몫 80% 안에서 펀딩 신청서의 '자금 사용 계획'대로 낸다.
3. 작가 몫은 신탁에서 연재 진행에 맞춰 나누어 지급한다: **상장 때 40% · 약정 회차 절반 연재 때 30% · 약정 회차 완결 때 30%.** 회차가 올라와 조건을 채우면 자동 지급한다. 지급한 금액을 작가 매출 몫에서 다시 회수하지 않는다(작가 몫 60%가 업계 하한이라 더 떼면 연재 중단 위험이 커진다). 투자자 보호는 최소 유보금 · 분할 지급 · 창작자 토큰 보호예수 · 귀책 반환 청구가 맡는다.

**[유통] Dibs = 창작물 유통 + 토큰 유통 연계**

1. 토큰증권이 상장되면 Dibs 플랫폼에서 회차별 유료 미리보기를 시작하고, 독자는 씨앗으로 결제해 먼저 감상한다. 정식 공개 시각이 되면 무료로 풀린다.
2. 토큰증권을 마켓에 상장하고, 회원은 마켓에서 매수 · 매도한다.
    - 매수 · 매도 수수료는 각각 0.015%(원 미만 버림)이며 **장외거래소·증권사 몫**이다.
    - 창작자 토큰은 보호예수 기간이 끝난 뒤 매도만 할 수 있다.
    - 투자자 계좌는 증권사가 관리하고, 계좌관리비는 Dibs가 증권사에 낸다.

**[수익 배분 · IP 확장]**

1. 1차 IP 순매출(유료 열람, 미리보기, 대여 · 소장 결제, 광고 수익)은 작가 60% · 투자자 30% · Dibs 10%로 나눈다. 원금 회수 전후로 비율은 바뀌지 않는다. 투자자 몫은 신탁을 거쳐 분기마다 토큰 보유자에게 배당한다. 토큰을 가진 창작자도 보유한 만큼 배당받는다.
2. Dibs는 에이전시로서 작품의 2차 IP와 해외 판권 계약을 추진한다.
    - 2차 IP: 드라마 · 애니 · 게임 판권, 단행본 출판, 굿즈 · 캐릭터 사업
    - 해외 판권: 해외 번역 연재, 해외 판권 수출
    - 2차·해외 IP 수익은 Dibs가 받은 금액에서 **실비만 빼고 1차와 같은 60/30/10**으로 나눈다. 계약서와 정산서 증빙이 있어야 등록할 수 있다. 분기 배당에 '2차 IP' 줄로 따로 표시해 함께 지급한다. Dibs 에이전시 몫은 이 10%뿐이다.
    - 선공개 독점 12개월 뒤 외부 플랫폼 연재 정산금도 Dibs 수령액 전체를 1차 순매출로 넣어 60/30/10으로 나눈다.
    - 성장 가능성: 연재 매출은 꾸준한 배당의 바탕이 되고, 2차 IP · 해외 판권이 성사되면 배당 재원이 늘어난다.

**[Dibs 수익 구조]**

- **들어오는 돈**
    - ① 펀딩 운영비: 펀딩 성공 시 모금액의 3%
    - ② IP 수익 정산 · 분배: 1차 순매출의 10%, 2차 · 해외 IP 순수익의 10%
    - ③ 상장 전 매출(굿즈·광고)의 30%(작가 70%)
- **나가는 돈**
    - 증권사에 내는 계좌관리비(토큰 발행 실비는 모금액 12%에서)
    - 외주 에이전시 비용(작가 몫에서)
    - 출석·이벤트 보너스 씨앗(마케팅비)
- **받지 않는 돈:** 마켓 거래 수수료(0.015%)는 장외거래소·증권사 몫이다. v2.2의 '② 유통 · 거래 수수료'는 뺐다(17-1).

### **2-2. 회원 인증 단계(Level)**

API `GET /me`의 `level`로 내려준다.

| 레벨 | 조건 | 가능한 것 |
| --- | --- | --- |
| L0 게스트 | 없음 | 탐색, 1화 열람 |
| L1 가입 | 휴대폰 번호 + SMS 인증 + 필수 약관 동의 `[시안 01-8, 01-9]` | 정식 공개 회차 무료 열람, 유료 미리보기 구매, 찜, 씨앗 충전·사용 |
| L2 본인인증 | PASS/카카오/토스/SMS 본인확인 `[시안 01-7]` → 실명·생년월일·CI 저장 | 이벤트 참여, 창작자 신청, 19세 작품 열람(만 19세 이상) |

- 본인인증 CI 기준으로 1인 1계정이다. L1 가입은 휴대폰 번호만으로 되므로 중복은 본인인증(L2) 때 확인한다. 같은 CI의 계정이 이미 있으면 이번 인증을 완료하지 않고 "이미 가입된 계정이 있어요(010-****-1920)"로 안내한 뒤 기존 계정 로그인으로 보낸다. 현재 계정에 남은 씨앗·찜은 1:1 문의를 받아 운영자가 기존 계정으로 옮기고, 현재 계정은 탈퇴 처리한다(M-02 계정 병합) ⚑.
- 만 19세 미만은 L3로 올라갈 수 없고 청약·매수는 `UNDERAGE`로 막는다 ⚑(투자 상품 특성). 생년월일은 본인인증 때 받는다.
- 투자성향 진단 결과가 '안정형'이면 L3 진입 시 경고 화면을 한 번 보여주고 확인을 받는다(진입 자체는 허용) ⚑.
- 모의 모드(시연)에서는 계좌 연결을 L3 표시에만 쓰고 청약은 막지 않는다. 실거래 모드는 계좌 연결이 필수다.

## **3. 핵심 정책**

### **3-1. 작품 생애주기**

**작품 상태 `work.status`**

| 상태 | 의미 | 앱 노출 | 진입 조건 |
| --- | --- | --- | --- |
| `DRAFT` | 작성 중 | × | 창작자가 생성 |
| `IN_REVIEW` | 공개 심사 대기 | × | 창작자가 심사 요청(회차 3개 이상 필수) |
| `REJECTED` | 반려 | × | 운영자 반려(사유 필수) → 창작자 수정 후 재요청 가능 |
| `PUBLISHED` | 공개(펀딩 전) | ○ | 운영자 승인 |
| `FUNDING` | 펀딩 진행 중 | ○ | 펀딩이 `OPEN`이 됨 |
| `FUNDING_FAILED` | 펀딩 실패 | ○(공개 유지) | 펀딩 마감 시 미달. 창작자는 `CFG.funding.retryCooldownDays`(30일) 후 재신청 가능(`RETRY_COOLDOWN`) |
| `ISSUING` | 발행 진행 중 | ○ | 펀딩 성공 |
| `LISTED` | 상장(거래 가능) | ○ | 운영자가 상장 처리 |
| `HALTED` | 거래 정지 | ○ | 운영자 조치(분쟁, 공시, 연재 중단 등) |
| `DELISTED` | 상장 폐지 | ○(종목 정보만) | 운영자 조치(17장 미결 항목 참고) |
| `HIDDEN` | 비공개 | × | 운영자 조치(권리 분쟁, 신고 등). `LISTED` 작품은 숨길 수 없고 `HALTED`로만 전환. `FUNDING`·`ISSUING` 작품은 펀딩 취소 또는 발행 실패 처리 후 숨긴다 |

- 앱에 보이는 상태는 API `display_status`로 내려준다. 서버는 작품 상태와 최근 펀딩 상태(`OPEN` → `FUNDING`, `FAILED` → `FUNDING_FAILED`, `ALLOCATED`·`ISSUING` → `ISSUING`, `ISSUE_FAILED` → `PUBLISHED`, `LISTED` → `LISTED`, `SUSPENDED` → `HALTED`, `TERMINATED` → `DELISTED`)를 합쳐 계산한다.

**작품 유형:** `WEBTOON` | `WEBNOVEL`

**연령 등급** `work.age_rating` ⚑: `ALL` | `15` | `19`. 창작자가 등록할 때 고르고 운영자가 심사 때 확정한다. `19` 작품은 본인인증(L2)으로 만 19세 이상이 확인된 회원만 회차를 열 수 있다(게스트·L1은 작품 상세까지, `ADULT_ONLY`). 썸네일에 '19' 배지를 붙인다.

**펀딩 취소 시:** 펀딩이 `CANCELED`되면 작품은 `PUBLISHED`로 돌아가고 재신청 대기 기간은 없다 ⚑.

**장르(고정 코드):** 판타지, 로맨스, 로판, 현판(현대판타지), 무협, 스릴러, 드라마, 코믹, SF, 액션, 일상, BL, GL ⚑(어드민에서 추가·수정 가능)

### **3-2. 콘텐츠 열람 정책**

- **상장 전**(`PUBLISHED`, `FUNDING`, `FUNDING_FAILED`, `ISSUING`): 작가가 공개한 회차는 무료다. **유료 미리보기를 열 수 없다**(운영자가 가격을 설정하면 `NOT_LISTED_YET`).
- **상장 후**: 회차별로 정식 공개 전에 유료 미리보기를 제공할 수 있다. 작가는 정식 공개 시각을 예약하고, 운영자만 미리보기 시작 시각과 회차별 가격(씨앗)을 정한다. 기본 가격은 `CFG.preview.defaultPrice`(300원 = 씨앗 3개). 미리보기 시작 시각은 상장 이후이면서 해당 회차의 정식 공개 시각(`free_unlock_at`)보다 빨라야 한다(`INVALID_FREE_AT`). 정식 공개 시각을 정하지 않으면 미리보기 시작 `CFG.preview.freeAfterDays`(21일) 뒤 무료로 풀린다.
- 정식 공개 전이고 미리보기가 열리기 전인 회차는 '예정'으로 표시한다. 미리보기가 시작되면 '미리보기 씨앗 n개'로 표시하고, 결제한 회원과 기존 열람권을 가진 회원에게 해당 회차를 연다. 정식 공개 시 구매 여부와 관계없이 무료로 열람할 수 있다.
- 미리보기는 해당 회차 1회 결제로 열람권을 준다. 구매 기록과 기존 대여·소장·리워드 열람권은 유지한다. 결제 수단은 3-4-3을 따른다(모든 출처 사용 가능).
- 게스트는 무료로 공개된 1화만 볼 수 있다. 유료 미리보기 구매나 2화 이상 진입 시 로그인 유도 시트를 띄운다(서버 응답 `401 LOGIN_REQUIRED`).
- 상장 작품의 유료 결제는 Dibs 매출 계정을 거치지 않고 신탁 계좌로 바로 들어간다(결제 시점 분할, 3-8-4).

### **3-3. 찜**

- 찜은 무료 관심 등록이다. L1 이상만 할 수 있고, 같은 작품에 한 번만 할 수 있다(토글).
- 찜하면 해당 작품의 알림을 받는다: 새 회차 공개, 펀딩 오픈, 펀딩 마감 24시간 전, 펀딩 결과, 상장, 배당 공지(보유자가 아닐 땐 상장 알림까지만).
- 찜 수(`work.dibs_count`)는 작품 카드, 상세, 랭킹에 노출한다. 1만 이상은 '1.2만'처럼 축약한다(소수 첫째 자리, 내림).
- 찜에는 우선 참여권·배정 우선권 같은 권리가 없다. 초과 청약 균등 배정은 전부 공개 추첨이다(3-5-4). 시안의 '공모 우선배정권 획득' 문구는 삭제한다(15장).
- 회차의 하트(좋아요)와 작품 찜은 서로 다른 기능이다. 회차 하트는 그 회차 1개에 대한 '좋아요'다.

### **3-4. 돈: 씨앗과 예치금**

**3-4-1. 왜 두 개로 나누는가 ⚑**

기획 요청은 "모든 돈을 씨앗 하나로"였다. 하지만 아래 이유로 **사용자에게 보이는 잔액을 '씨앗'과 '예치금' 두 개**로 나눈다.

1. 씨앗 : 앱스토어 정책상 앱 안에서 디지털 콘텐츠(회차별 유료 미리보기)를 팔려면 애플·구글 인앱결제를 써야 한다. 인앱결제로 산 재화는 현금 출금이나 증권 매수에 쓸 수 없다.
2. 예치금 : 증권사 계좌에 보관되고 배당·매도 대금·환불이 들어와 출금되는 돈이다. 출금할 수 없는 씨앗과 한 잔액으로 섞으면 출금 가능액과 환불 규칙을 화면에서 설명할 수 없다.

**3-4-2. 비교**

| 구분 | 씨앗 | 예치금 |
| --- | --- | --- |
| 단위 | 1씨앗 = 100원(장부는 원) | 원 |
| 용도 | 회차별 유료 미리보기, 굿즈, 이벤트 | 펀딩 참여, 마켓 매수 |
| 들어오는 길 | ① 인앱결제 충전(`IAP`) ② PG 결제 충전(카드·계좌이체, `PG`) ③ 예치금에서 전환(`CONVERTED`) ④ 운영자 지급·출석·묶음 보너스·쿠폰·포인트 전환(`BONUS`) | ① 본인 계좌에서 입금 ② 배당금 ③ 매도 정산금(수수료 차감 후) ④ 펀딩 환불(미배정분 포함) ⑤ 특별 분배(연재 중단·조기 완결·유보금) |
| 출금 | 불가. 환불만(3-4-5) | 본인 명의 연결 계좌로 출금 가능 |
| 전환 | 씨앗 → 예치금 **불가** | 예치금 → 씨앗 **가능**(1:1, 수수료 0, 취소 불가, 실거래 모드 전용) |

**3-4-3. 씨앗 사용처와 출처 규칙**

씨앗은 출처별로 묶음(lot, `coin_lots`)을 만들어 관리한다. 잔액의 기준은 원장이고 묶음은 출처·유효기간·환불 판단용 보조 장부다.

| 사용처 | 사용 가능한 씨앗 출처 | 차감 순서 |
| --- | --- | --- |
| 회차별 유료 미리보기 | **모든 출처** ⚑ | `BONUS` → `CONVERTED` → `PG` → `IAP`(같은 출처 안에서는 만료 임박 순) |
| 굿즈·이벤트 | 모든 출처 | 위와 같음 |
- 미리보기 결제 출처를 v2.2의 `IAP`·`BONUS`에서 모든 출처로 넓혔다. 화면이 예치금으로 산 씨앗으로 회차를 열고, 국내 앱은 외부 결제를 쓸 수 있다. 순매출 계산에서는 출처와 관계없이 결제 수수료 `CFG.revenue.inappFeeRate`(30%)를 똑같이 뺀다.
- `BONUS` 씨앗의 유효기간은 지급일로부터 `CFG.coin.bonusExpiryDays`(90일)이다. 유료 씨앗(`IAP`, `PG`, `CONVERTED`)은 5년이다(상법상 상사채권 소멸시효 기준) ⚑. 만료는 매일 배치(`POST /admin/jobs/expire-coins`)로 처리한다.
- 충전 상품(⚑, 어드민에서 변경 가능, `[시안 08 씨앗 구매]`):

| 상품 ID | 지급 씨앗 | PG 결제 | 인앱 결제 |
| --- | --- | --- | --- |
| `seed10` | 10개 | 1,000원 | 1,100원 |
| `seed30` | 30개 | 3,000원 | 3,300원 |
| `seed55` | 50개 + 보너스 5개 | 5,000원 | 5,500원 |

- 인앱결제 가격은 지급 금액 × 110%(`CFG.coin.iapMarkupRate` 10%)이며 실제 상품은 스토어 가격 등급에 맞춘다. 차액은 스토어 수수료 보전분이다 ⚑. 화면에는 결제 금액과 지급 씨앗을 모두 표시한다.
- 묶음 보너스 씨앗은 함께 산 유료 묶음에 연결된다(`parent_lot_id`). 유료 묶음을 환불하면 보너스의 남은 양도 회수한다.
- 잔액 표시: 씨앗 합계와 함께 출처별 사용 가능량을 보조로 보여준다(`GET /wallet/coin/lots`).

**3-4-4. 예치금 입금·출금**

- **입금:** 회원마다 발급되는 전용 입금 계좌(가상계좌 또는 증권사 연계 계좌)로 본인 명의 계좌에서 이체한다. 입금자명이 회원 실명과 다르면 입금을 반환한다. 입금 확인은 웹훅으로 실시간 반영한다.
    - 입금 계좌는 제휴 증권사가 발급한다(`DepositProvider` 어댑터, 8장. 로컬·스테이징은 Mock).
- **출금:** 연결된 본인 명의 계좌로만 출금한다. 최소 출금액은 `CFG.withdraw.min`(1,000원, `WITHDRAW_MIN`)이고 출금 수수료는 없다. 출금 가능액 = 예치금 − 미체결 매수 주문 묶임액(예상 거래 수수료 포함) − 진행 중 펀딩 청약 묶임액이다.
    - 1회 `CFG.withdraw.autoLimit`(1,000만 원) 이하는 즉시 처리, 초과 건은 운영자(FIN) 승인 후 처리한다. 출금 1회 상한은 따로 두지 않는다.
    - 처리 시간: 즉시 처리 건은 접수 후 5분 이내, 승인 건은 영업일 기준 1일 이내.
- **계좌 연결:** 실명 계좌 조회(예금주 실명 일치) 후 1원 인증(입금자명 4자리 숫자) ⚑. 1인 1계좌만 연결하며 변경할 수 있다. 기존 계좌를 바꾼 직후 `CFG.withdraw.accountChangeHoldHours`(24시간) 동안은 출금을 막는다(`ACCOUNT_CHANGE_HOLD`, 보안). 처음 연결할 때는 막지 않는다.

**3-4-5. 씨앗 환불**

- `PG` 충전 씨앗(`POST /wallet/coin/lots/{id}/refund`):
    - 결제 후 `CFG.coin.pgRefundDays`(7일) 이내이고 한 번도 쓰지 않았으면(함께 받은 묶음 보너스 포함) **결제 취소**한다.
    - 그 밖에는 남은 씨앗만큼 본인 계좌로 환불한다(환불 수수료 없음). 남은 금액이 `CFG.coin.refundMin`(1,000원) 미만이면 환불할 수 없다(`REFUND_TOO_SMALL`) ⚑.
    - 어느 쪽이든 함께 받은 묶음 보너스의 남은 양은 회수한다(보너스만 쓰고 원금을 취소하는 경로를 막는다).
- `IAP` 충전 씨앗: 환불은 애플·구글 정책을 따른다. 스토어 환불 알림(App Store Server Notification, Google RTDN)을 받으면 해당 묶음 전체를 회수한다(`POST /admin/coin/lots/{id}/iap-refund`). 이미 써서 잔액이 모자라면 부족분을 `coin_debt`로 기록하고 다음 충전 때 먼저 상계한다. 원장 잔액은 음수로 두지 않는다.
- `CONVERTED`, `BONUS` 씨앗: 환불하지 않는다.

### **3-5. 펀딩**

**3-5-1. 펀딩 개설 조건**

- 창작자가 `PUBLISHED` 작품에 펀딩을 신청하고, 운영자가 심사해 조건을 확정한다(심사 때 덮어쓸 수 있는 조건은 14장 '펀딩별').
- 한 작품에 진행 중인 펀딩은 하나뿐이다(`FUNDING_ALREADY_ACTIVE`). 실패 후 30일이 지나야 다시 신청할 수 있다(`RETRY_COOLDOWN`).
- 목표 금액: `CFG.funding.minTarget`(**1,000만 원**, 검토안) 이상 `CFG.funding.maxTarget`(5억 원) 이하.
- 목표 금액 상한 ⚑: **월 유료 팬 추정 × 1명당 상품 기간 투자자 몫(세후) × 70%**, 100만 원 단위 내림.
    - 상장 전에는 유료 구매자가 없으므로 월 유료 팬 = 최근 4주 파일럿 열람자(회차 뷰어 진입 고유 사용자) × 가정 결제율 `CFG.funding.assumedPayRate`(15%)로 추정한다(`fans_basis = READERS_X_PAY_RATE`).
    - 15%는 플랫폼 평균이라 작품 단위로는 낙관값이어서 안전율 70%를 둔다.
    - MVP는 상한과 개설 조건을 화면에 보여주기만 하고, 강제(`CFG.funding.enforceGate`)는 운영 데이터가 쌓인 뒤 켠다.
- 모집 기간: 7~60일.
- 리워드 티어: 최대 5개.
- 연재 약정: 약정 회차 기본 40화(최소 20화), 한 달 4화. 공모 전 비축분 ≥ 약정 회차의 25%(운영에서 강제)(3-9).

**3-5-2. 청약**

- L3(만 19세 이상, 투자성향 확인) 회원만 청약한다. 창작자는 자기 작품에 청약할 수 없다.
- 1조각(1,000원) 단위로 청약하고 청약금은 예치금에서 묶인다. 위험 고지와 해지 규칙 동의가 필요하다.
- 1인 청약 한도: **3,000만 원과 발행액 5% 중 작은 금액.** 투자 경험이 없다고 답한 회원은 10만 원.
- 종목당 1인 보유 한도 10%(3-7-4)와 일반투자자 연간 순매수 한도 1억 원(장외거래소 기준)도 함께 지킨다.
- 마감 60분 전부터는 감액·취소할 수 없다.

**3-5-3. 마감**

- 목표 미달: 묶인 예치금을 전액 해제하고 펀딩은 `FAILED`, 작품은 `FUNDING_FAILED`.
- 목표 달성: 배정(3-5-4) 후 미배정분을 돌려주고 발행 절차(3-6)로 넘어간다.

**3-5-4. 초과 청약 배정**

- **균등 20%:** 발행량의 20%를 참여자 수로 나눠 똑같이 준다. 균등분이 참여자 수보다 적으면 공개 추첨으로 1조각씩 준다. 추첨 순서는 `sha256(펀딩 번호:청약 번호)`라 누구나 다시 계산할 수 있다.
- **비례 80%:** 남은 물량을 남은 청약 수량에 비례해 나눈다. 단수는 먼저 청약한 순으로 1조각씩 준다.
- 찜·이전 활동에 따른 우선 배정은 없다 ⚑.

**3-5-5. 모금액 배분과 창작자 토큰**

| 항목 | 값 |
| --- | --- |
| 작가 몫 | 80%. 신탁 보관 후 상장 40% · 약정 절반 30% · 완결 30% |
| 발행 실비 | 12% |
| 최소 유보금 | 5%(신탁, 3-9) |
| Dibs 운영비 | 3% |
| 창작자 토큰 | 전체 발행량의 5% = 투자자 배정 수량 × 5/95(내림). 예: 투자자 1,000조각 → 창작자 52조각 |
| 보호예수 | 상장 후 12개월 매도 불가(`CREATOR_LOCKUP`). 매수는 언제나 불가(`SELF_TRADE_FORBIDDEN`) |
| 공시 | 모금액 100원당 쓰임(작가 80 · 발행 실비 12 · 유보금 5 · Dibs 3), 창작자 토큰 비율·보호예수 |

### **3-6. 발행·상장**

- 절차: `REQUESTED` → `FILED`(증권신고·공시) → `ISSUED`(증권 식별번호·수탁기관 확정) → `LISTING_SCHEDULED` → `LISTED`. 운영자가 어드민에서 단계를 진행한다.
- 발행이 실패하면 `ISSUE_FAILED`로 바꾸고 배정된 청약금을 전액 환불한다.
- 계약 효력은 발행 시점에 생긴다. 상장 때 모금액 배분과 창작자 토큰 배정, 작가 1차 지급(40%)이 함께 처리된다.
- 상장일 기준가는 공모가(1,000원)다.
- **만기 없음.** 고정 운용 기간·예정 만기 없이 발행한다. 기간 만료·저매출 자동 종료는 쓰지 않는다. 권리가 끝나는 길은 두 가지다.
    - 작가 매입: 펀딩 때 선택한 경우만. 매입가 = 최근 4분기 보유자 배당 합계 × 3.
    - 운영자 상장폐지: 17장 미결.
- 선공개 독점: 상장 후 12개월은 Dibs에서만 먼저 공개한다. 그 뒤 외부 연재 정산금은 3-8로 들어온다.

### **3-7. 마켓**

**3-7-1. 거래 시간** 24시간. 매일 04:00~04:30(KST) 점검 중에는 주문할 수 없다(`MARKET_MAINTENANCE`). 미체결 주문은 자정에 자동 취소한다.

**3-7-2. 주문**

- **지정가:** 같은 가격끼리 시간 순으로 체결한다.
- **시장가:** 최우선 반대 호가 한 단계에서 체결하고 남은 수량은 취소한다. 반대 호가가 없으면 접수하지 않는다(`NO_COUNTER_ORDER`).
- 호가 단위: 10원.
- 가격제한폭: 기준가(전일 종가) ±30%.
- 자기 주문끼리는 체결하지 않는다.

**3-7-3. 수수료** 매수·매도 체결 금액에 각각 0.015%(원 미만 버림). 장외거래소·증권사 몫이며 Dibs 수입이 아니다. 청약 수수료는 0원이다. 매수 주문 때는 예상 수수료를 함께 묶고 체결 후 차액을 돌려준다.

**3-7-4. 한도**

- 종목당 1인 보유 한도: 전체 발행량의 10%(보유 + 미체결 매수 + 새 주문, `HOLDING_LIMIT_EXCEEDED`).
- 일반투자자 연간 순매수 1억 원(장외거래소별), 종목당 3,000만 원. 적격투자자는 연 10억 원, 종목당 1억 원.
- 만 19세 미만 매수 불가(`UNDERAGE`). 투자성향 확인 후 주문 가능.

**3-7-5. 종목 화면 지표**

- 최근 분기 토큰당 배당(`last_dist_per_token`): 지급까지 마친 분기 중 가장 최근 분기. 진행 중 분기는 제외한다.
- 연 배당수익률(`annual_dist_yield`): 최근 확정 4분기 토큰당 배당 합 ÷ 현재가.

### **3-8. 배당·공시**

**3-8-1. 순매출**

| 매출 종류 | 들어오는 것 | 빼는 것 |
| --- | --- | --- |
| `PAID_EPISODE` | 상장 후 유료 미리보기(씨앗) | 결제 수수료 30% |
| `AD` | 광고(MVP는 운영자 수기 입력) | 실비 |
| `GOODS` | 굿즈 | 원가·배송 실비 |
| `EXTERNAL_SERIAL` | 독점 12개월 뒤 외부 플랫폼 연재 정산금(Dibs 수령액 전체) | 실비. 정산서 증빙 필수 |
| `SECONDARY_IP` | 2차·해외 IP(판권·출판·캐릭터 라이선스·해외 연재) | 실비. 계약서·정산서 증빙 필수(`EVIDENCE_REQUIRED`) |

**3-8-2. 배분** 분기 순매출을 작가 60% · 투자자 30% · Dibs 10%로 나눈다. 회수 전후 전환은 없다. 작가 몫은 유보 없이 그대로 지급한다.

**3-8-3. 배당 지급**

- 투자자 몫 30%를 분기 말 보유 조각 수에 비례해 나눈다. 창작자 토큰도 똑같이 받는다.
- 배당소득세 15.4%(소득세 14% + 지방소득세 1.4%)를 원천징수한다.
- 분기 종료 다음 달 10일에 예치금으로 지급한다.
- 상장 전 매출(굿즈·광고)은 작가 70% · Dibs 30%로 나누고 배당하지 않는다.

**3-8-4. 공시와 대사**

- 결제 시점 분할: 상장 작품의 유료 결제는 신탁 계좌로 바로 들어간다.
- 결제 기록 연쇄 해시: 회원 식별자 없이 공시한다.
- 분기별 매출 종류별 내역과 증빙 링크.
- 펀딩 공시: 모금액 쓰임, 창작자 토큰, 연재 약정과 진행률, 손익분기 규모.

### **3-9. 연재 약정과 위험**

| 상황 | 처리 |
| --- | --- |
| 미리 알린 휴재 | 시즌 중 누적 8주까지 기한에서 빼 준다 |
| 지연(태업) | 한 달치(4화) 이상 밀리면 경고하고 보유자·증권사에 알린다. 석 달치(12화) 밀리면 작가 귀책 중단 |
| 약정 회차 완결 | 남은 작가 지급분 지급. **최소 유보금 전액 작가에게** |
| 조기 완결 | 남은 작가 지급분과 유보금을 연재 비율(연재 회차 ÷ 약정 회차)만큼 작가, 나머지는 보유자에게 나눈다 |

### **3-10. IP 확장**

- Dibs는 에이전시로서 2차·해외 IP 계약을 추진한다. 계약 금액에서 실비(번역·법무·중개)를 뺀 순수익을 3-8의 `SECONDARY_IP`로 등록한다.
