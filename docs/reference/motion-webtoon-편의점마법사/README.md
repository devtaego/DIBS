# 레퍼런스: 「새벽 세시의 편의점 마법사」 1화 모션웹툰

- `index.html` + `img/`: 컷 이미지와 말풍선을 스크롤로 연출한 원본 (브라우저로 열기)
- 영상판(1080x1920, 2분 40초, 소리 있음)은 720p로 줄여 앱 데모 쇼츠에 넣었다: `app/public/shorts/pmb.mp4`
- 표지 `app/public/covers/pmb.jpg` 는 영상 2초 지점 제목 화면

쇼츠 모션코믹(`app/scripts/make_demo_shorts.py`)을 다듬을 때의 기준:
컷마다 따로 등장, 말풍선은 컷보다 늦게 하나씩, 효과음(탁)은 크게 튀어나오게, 배경에 비·빛 같은 분위기 효과.
