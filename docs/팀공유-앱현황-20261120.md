## 2. 화면 구성 (하단 탭 5개)

| 탭 | 내용 |
|---|---|
| 홈 | 내 투자 자산(투자한 작품 / 청약 중 / 예치금), DIBS IP 지수, 청약 마감 임박, 지금 모집 중 |
| 탐색 | 추천 \| 랭킹. 추천 = 전체 / 카테고리(연령대·장르) / 필터(형식·공모 단계·정렬). 랭킹 = 상위 3개 + 더 보기. 검색(뒤로가기 있음) |
| 쇼츠 | 쇼츠 \| 찜한 작품. 5개 영상 순환, 상단 칸 막대(ㅡ ㅡ ㅡ)가 재생만큼 차오름·끌어서 이동. 공모 전/중/종료별 하단 카드, 댓글(욕설 필터), 공유 |
| 증권 | 내 조각(평가금액·손익·보유) / 거래 중인 조각 / 곧 거래가 시작돼요 |
| MY | 프로필 편집, 출석 체크, 내 펀딩·관심 작품·거래 내역·정산·투자 한도·서류함, 투자성향·연결 계좌·알림 설정, 고객센터·약관 |

## 3. 핵심 흐름

1. **콘텐츠 → 투자**: 쇼츠/회차 하단 바(이전화 · 좋아요 · 조각 사기 · 다음화) → 펀딩 상세 → 청약
2. **청약**: 금액(조각 단위) → 위험 고지·부적합 확인 → **키움증권 스플래시 → 키움 결제 화면(수량 고정)** → 완료 → 내 펀딩(청약·배정 탭)·MY·지갑·모집률에 바로 반영
3. **돈**: 지갑 → 충전/출금 → 키움 화면 → 완료 (출금은 모의 모드에서 즉시 처리)
4. **상장 후**: 증권 탭 → 종목 → 사기/팔기 (100원 단위, ±30%)
5. **알림**: 청약 마감 2일 전 (청약자·찜한 사람), 공모 시작, 배정, 상장

## 4. 이번에 정한 정책

| 항목 | 결정 | 이유 |
|---|---|---|
| 모집률 상한 | **두지 않음** (기획서대로) | 넘게 모이면 목표 수량만 발행, 균등 20% + 비례 배정, 남은 돈 환불. 100% 초과 모집률은 수요 지표 |
| 청약 단위 | **1조각 = 1만 원, 조각 단위로만** | 공모는 정해진 가격으로 수량을 사는 것. 10,532원 같은 금액 불가 |
| 거래 가격 | **100원 단위** (서버 검증) | 상장 후엔 시세가 변하므로 11,500원 같은 가격은 정상 |
| 출석 보상 | **7일 사다리 50·50·200·50·50·50·300코인** | 3일째 1화(300코인), 7일 2.5화. 한 달 최대 약 3,200코인 |
| 키움 포인트 | **포인트 → 코인 한 방향, 1P = 1코인** | 유료 회차 체험 유도. 코인 → 예치금/투자는 막아서 투자 유인 논란 차단 |
| 리워드 성격 | 출석·포인트·쿠폰은 모두 **코인(열람 전용)** | 투자 권유·유인 소지 없앰 |
| 투자성향 | 5단계 (안정형 ~ 공격투자형) | DIBS 조각 = 1등급(매우 높은 위험). 공격투자형이 아니면 부적합 확인 동의 필요 |
| 화면 문구 | '모의'·'시연' 문구 쓰지 않음 | 실제 서비스처럼 보이게 (PC 휴대폰 틀 밖 안내 한 줄만) |

## 5. QA 점검 결과

- 화면 39개 순회(오류·undefined·NOT_FOUND·'모의' 문구) 전부 통과

- 백엔드 테스트 70개, 타입 검사, iOS/Android 번들 빌드 통과
- 점검 스크립트: `app/scripts/qa/` (데모 빌드 후 `serve_range.py`로 띄우고 실행)

### 장점
1. 쇼츠 → 작품 → 청약 → 키움 결제 → 반영 → 상장 거래 → 정산까지 끊김 없는 흐름, 백엔드는 복식부기 원장·배정·발행·권리 종료까지 실제 규칙으로 계산
2. 투자자 보호가 흐름 안에 들어 있음 (투자성향·부적합 확인·위험 고지·한도·코인/예치금 분리)
3. 공모 단계(전/중/종료)별로 카드 색·버튼이 달라 상태가 한눈에 보임
4. 오프라인 시연 가능 (정적 데모·Expo Go 번들 미디어·고정 시각)

### 시연 전 실폰 체크리스트 (5분)
1. Expo Go 실행 → 상단바 여백, 쇼츠 자동 재생·소리
2. 청약 → 키움 스플래시 → 결제 → 내 펀딩 반영
3. 지갑 충전·출금 숫자
4. 유료 회차를 키움 포인트로 열기
5. 댓글 입력 시 키보드가 입력창을 가리지 않는지
6. 끝나면 MY → "처음 상태로 되돌리기"
